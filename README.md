# وصله — Vasleh

نرم‌افزار ماژولار همه‌کاره با PHP خالص، بدون فریم‌ورک و بدون بیلد — طراحی‌شده برای هاست اشتراکی.

هر ماژول یک «وصله» است که به هسته وصل می‌شود: هسته هیچ ماژولی را نمی‌شناسد؛ پوشه‌ی ماژول تازه که به `modules/` اضافه شود، خودش کشف و لود می‌شود و نیازی به هیچ تغییری در هسته نیست.

## ساختار

```
index.php    فقط درخواست‌ها را جمع می‌کند و به هسته می‌دهد
core/        هسته: روتینگ، کانتینر سرویس، لودر ماژول، ویو
modules/     ماژول‌ها؛ نام هر پوشه = نام ماژول، هر ماژول یک core.php دارد
storage/     دیتابیس و فایل‌های زمان اجرا (از وب بسته است)
```

## ماژول‌های فعلی

- **sqlite** — مدیریت دیتابیس (سرویس `db`) + صفحه وضعیت دیتابیس در مدیریت
- **session** — سشن امن روی دیتابیس، ورود مدیر، کاربران و دسترسی‌ها (CSRF روی همه فرم‌های مدیریت)
- **admin** — خودِ پنل مدیریت هم ماژول است: داشبورد، مدیریت ماژول‌ها، ساخت و ویرایش ماژول
- **front** — فرانت‌اند سایت هم ماژول است

## اجرا

```bash
php -S localhost:8000
```

یا روی هاست اشتراکی: فایل‌ها را در ریشه سایت بریزید؛ `.htaccess` دسترسی مستقیم به `core/` و `modules/` و `storage/` را می‌بندد.

## ⚠️ اولین ورود

در اولین اجرا اگر کاربری نباشد، کاربر `admin` با رمز `admin123` ساخته می‌شود. **قبل از انتشار عمومی حتماً رمز را عوض کنید** (قدم نصب‌کننده در راه است).

فایل‌های `storage/database.sqlite` و `storage/app.key` (کلید امضای سشن) هرگز نباید وارد گیت شوند — در `.gitignore` هستند.
